DESIGN

Session-scoped by design

The browser generates random keys and nonces, then encrypts entirely on the client. Refreshing or clearing the session loses the decryption and signing keys. Public keys, envelopes, and signatures can be copied; private keys cannot be exported.

Web Crypto provides HKDF and AES-GCM. The JavaScript post-quantum implementation is not guaranteed constant-time and is not independently security-audited. A browser session is not a substitute for managed custody, authenticated key exchange, or a production cryptographic service.
